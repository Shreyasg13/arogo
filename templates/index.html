Save a one-file backup of your health data, and restore it later — handy if you run Arogo on your own server. Restoring replaces your current data with the backup's, so you'll get to review it first.

Connect Fitness App

Connect your fitness apps to automatically import workouts. Each service requires API credentials in your .env file.

S
Strava
Running, cycling & more
1. strava.com/settings/api → create app
2. Set redirect: localhost:5000/oauth/strava/callback
3. Add STRAVA_CLIENT_ID + STRAVA_CLIENT_SECRET to .env
G
Garmin Connect
GPS watches & fitness trackers
1. Apply at developer.garmin.com
2. Add GARMIN_CONSUMER_KEY + GARMIN_CONSUMER_SECRET to .env
🍎
Apple Health
iPhone & Apple Watch
1. iPhone → Health → Profile → Export All Health Data
2. Upload the ZIP file here — no API keys needed
G
Google Fit
Android & Wear OS
1. console.cloud.google.com → Enable Fitness API
2. Add GOOGLE_CLIENT_ID + GOOGLE_CLIENT_SECRET to .env
